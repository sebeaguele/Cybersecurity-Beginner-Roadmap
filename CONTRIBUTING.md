# 🤝 Contributing

Thanks for helping make cybersecurity easier to break into! Contributions of all sizes are welcome.

## What we're looking for

- 🔗 **Broken links:** fix or replace them
- 🆓 **Free, high-quality resources** that a beginner can actually follow
- 🧰 **Open-source tools** that meet the criteria below
- ✏️ **Clearer explanations** for anything confusing

## Rules for resources

1. **Free-first.** Mark any paid resource with 💲.
2. **Beginner-friendly.** If it assumes years of experience, it belongs in a later phase.
3. **No piracy, no cheat dumps, no affiliate links.**
4. **Legal practice only.** Labs must be designed for practice, or run on systems you own.

## Rules for tools (TOOLS.md)

A tool must be:
- Open source with a recognised licence
- Actively maintained, with commits in the last 12 months
- Documented well enough for a beginner to install and run
- Given a difficulty rating: 🟢 / 🟡 / 🔴

## How to contribute

1. Fork this repo
2. Make your change in a branch
3. Open a pull request explaining **what** you changed and **why** it helps beginners

Not comfortable with Git yet? Open an **Issue** with your suggestion instead. That counts too!
